fruit-classification-final.ipynb包含了本项目模型实现的全部代码（未训练）；
streamlit_test.py 包含了模型可视化与应用拓展的全部代码。
其余代码为分散模型训练。

## ✨ 功能特性

- **核心功能1**: 水果识别
- **核心功能2**: 给出营养价值

## 🚦 使用说明
- **水果分类**：运行streamlit_test.py来打开可视化界面，通过在网页上传水果图片来进行水果预测以及说过营养价值输出。
- **数据库**：运行database_creation.py来实现数据库的建立和数据插入。
